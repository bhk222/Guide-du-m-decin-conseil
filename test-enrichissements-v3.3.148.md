## ✅ CRITÈRES DE VALIDATION

### Pour chaque test
1. ✅ **Reconnaissance** : Séquelle identifiée (pas de "no_result")
2. ✅ **Pertinence** : Lésion proposée correspond au contexte
3. ✅ **IPP** : Taux dans fourchette barème attendue
4. ✅ **Justification** : Inclut éléments cliniques mentionnés

### Métriques cibles
- **Taux reconnaissance** : ≥ 95% (23/24 tests minimum)
- **Pertinence** : 100% (si reconnu, doit être correct)
- **Précision IPP** : ± 5% fourchette attendue
