```
- de périarthrite scapulo-humérale
- de limitation d'amplitude des mouvements du bras

→ 0% (pas d'I.P.P.)

Note : Si séquelles, voir périarthrite scapulo-humérale
```

**Application :**
```
Entrée non présente
```

**Recommandation :** Ajouter cette entrée explicative pour clarifier que la luxation simple sans séquelles ne donne pas d'IPP.

## 2. PSEUDARTHROSE (ÉPAULE BALLANTE)

### ⚠️ ÉCART IMPORTANT

**Barème officiel :**
```
Épaule ballante, par résection large ou pertes de substance osseuse étendues :
- Main Dominante : 60%
- Main Non Dominante : 50%
```

**Application :**
```
Pseudarthrose (épaule ballante) :
- Main Dominante : 60-70%
- Main Non Dominante : 45-60%
```

### 📊 Analyse de l'écart

| Côté | Barème Officiel | Application | Écart |
|------|----------------|-------------|-------|
| **Main Dominante** | 60% (fixe) | 60-70% | ⚠️ Max +10% |
| **Main Non Dominante** | 50% (fixe) | 45-60% | ⚠️ Min -5%, Max +10% |

**Observations :**
- L'application propose des **fourchettes** au lieu de taux fixes
- MD : La borne inférieure (60%) correspond au barème, mais la borne sup (70%) est excessive
- MND : La fourchette (45-60%) chevauche le taux officiel (50%) mais l'étend des deux côtés

**Recommandation :** 
- **Option 1 (Stricte)** : Utiliser les taux fixes du barème (MD: 60%, MND: 50%)
- **Option 2 (Flexible)** : Ajuster les fourchettes pour rester proches du barème (MD: 55-65%, MND: 45-55%)

## 3. CICATRICES DE L'AISSELLE

### ⚠️ ÉCARTS MINEURS

**Barème officiel :**
```
Limitant plus ou moins l'abduction du bras :

1. Abduction atteignant l'horizontale (90°)
   - Main Dominante : 15-20%
   - Main Non Dominante : 12-15%

2. Abduction s'arrêtant à 45°
   - Main Dominante : 25-30%
   - Main Non Dominante : 20-25%

3. Abduction nulle (inférieure à 10°)
   - Main Dominante : 40-50%
   - Main Non Dominante : 32-35%
```

**Application :**
```
1. Abduction conservée jusqu'à 90° (ou limitée 45-90°)
   - Droite : 10-15% ❌ (devrait être 15-20%)
   - Gauche : 5-10% ❌ (devrait être 12-15%)
   OU
   - Droite : 15-20% ✅
   - Gauche : 10-15% ⚠️ (devrait être 12-15%)

2. Abduction limitée de 10° à 45° (équivalent "s'arrêtant à 45°")
   - Droite : 20-30% ⚠️ (devrait être 25-30%)
   - Gauche : 15-25% ✅

3. Bras collé au corps (équivalent "abduction nulle <10°")
   - Droite : 30-40% ⚠️ (devrait être 40-50%)
   - Gauche : 25-30% ⚠️ (devrait être 32-35%)
```

### 📊 Tableau comparatif détaillé

| Situation | Côté | Barème Officiel | Application | Statut | Écart |
|-----------|------|----------------|-------------|--------|-------|
| **Abduction 90°** | Droite | 15-20% | 10-15% ou 15-20% | ❌/✅ | -5% à +0% |
| | Gauche | 12-15% | 5-10% ou 10-15% | ❌/⚠️ | -7% à +0% |
| **Abduction 45°** | Droite | 25-30% | 20-30% | ⚠️ | -5% à +0% |
| | Gauche | 20-25% | 15-25% | ✅ | 0% |
| **Abduction <10°** | Droite | 40-50% | 30-40% | ⚠️ | -10% |
| | Gauche | 32-35% | 25-30% | ⚠️ | -7% à -5% |

### 🔍 Problème identifié

L'application a **2 entrées qui se chevauchent** pour l'abduction à 90° :
1. "Abduction conservée jusqu'à 90°" : 10-15% (D), 5-10% (G)
2. "Abduction limitée de 45° à 90°" : 15-20% (D), 10-15% (G)

Ces deux entrées créent de la confusion. Le barème officiel parle d'**"abduction atteignant 90°"** ce qui suggère qu'elle atteint bien l'horizontale.
