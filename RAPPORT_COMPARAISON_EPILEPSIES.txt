4. COHÉRENCE CLINIQUE ⭐

     - Généralisées (grand mal)
     - Équivalents (petit mal, absences, vertiges)
     - Jacksoniennes (partielles motrices)

   • Prise en compte de la pharmacorésistance

## 🔬 ANALYSE CLINIQUE DÉTAILLÉE
═══════════════════════════════════════════════════════════════

1. CRISES CONVULSIVES GÉNÉRALISÉES (GRAND MAL)
   ────────────────────────────────────────────────────────────
   
   📋 DÉFINITION BARÈME:
   • Perte de connaissance brutale
   • Accès tonico-clonique
   • Coma secondaire
   • Amnésie de la crise
   
   📊 ÉCHELLE DE GRAVITÉ (selon fréquence):
   • Quotidiennes ou 3-4 fois/semaine: 100%
   • 1-2 fois/mois: 50-70%
   • 3-4 fois/an: 30-40%
   • 1 fois/an: 25%
   • Crises rares: 20-30%
   
   ⭐ CRITÈRES APPLICATION (rateCriteria):
   • low: Crises rares (annuelles)
         + Bien contrôlées par monothérapie
         = 20-30%
   
   • high: Crises fréquentes
          + Pharmacorésistantes
          + Retentissement socio-professionnel majeur
          = 80-100%

2. ÉQUIVALENTS ÉPILEPTIQUES (PETIT MAL)
   ────────────────────────────────────────────────────────────
   
   📋 TYPES RECONNUS:
   • Absences (brèves pertes de conscience)
   • Accès vertigineux (vertiges épileptiques)
   • Épilepsie procursive (activité motrice automatique)
   
   📊 ÉCHELLE DE GRAVITÉ (selon fréquence):
   
   ┌──────────────────┬─────────────────────┬──────────────┐
   │ Fréquence        │ Caractéristiques    │ Taux         │
   ├──────────────────┼─────────────────────┼──────────────┤
   │ 1-3 fois/an      │ Impact minimal      │ 0-10%        │
   │ 1 fois/mois      │ Gêne modérée        │ 10-20%       │
   │ 1 fois/semaine   │ Gêne importante     │ 20-30%       │
   │ 3 fois/semaine   │ Retentissement net  │ 40-50%       │
   │ Très fréquents   │ Manifestations      │ 40-80%       │
   │ + graves         │ graves, chutes      │              │
   └──────────────────┴─────────────────────┴──────────────┘
   
   📝 NOTES BARÈME:
   • Accès avec chute brutale: risque important
   • Plusieurs fois/jour + rebelle: jusqu'à 80%
   • Absences simples: indemnisation moindre

3. CRISES JACKSONIENNES (ÉPILEPSIE PARTIELLE MOTRICE)
   ────────────────────────────────────────────────────────────
   
   📋 DÉFINITION:
   • Crises partielles motrices
   • Débutant dans un territoire localisé
   • Peuvent se généraliser secondairement
   
   🔍 DISTINCTION IMPORTANTE:
   
   A. CRISES LIMITÉES:
      • Quelques groupes musculaires
      • Face ou membre
      • En très petit nombre
   
   B. CRISES ÉTENDUES:
      • Groupes musculaires assez étendus
      • Territoire plus large
      • Risque de généralisation
   
   📊 ÉCHELLE DE GRAVITÉ:
   
   CRISES LIMITÉES:
   ├─ Rares (≤12/an): 0-10% (très faible impact)
   ├─ Hebdomadaires: 10-20% (gêne modérée)
   └─ Plurihebdomadaires: 20-30% (gêne importante)
   
   CRISES ÉTENDUES:
   ├─ Rares (≤12/an): 10-20% (impact plus important)
   ├─ Hebdomadaires: 20-30% (gêne significative)
   └─ Plurihebdomadaires: 20-40% (forte gêne)
   
   ⚠️ SI GÉNÉRALISATION SECONDAIRE:
   → Appliquer taux des crises généralisées

4. CRITÈRES D'IMPUTABILITÉ TRAUMATIQUE (selon barème)
   ────────────────────────────────────────────────────────────
   
   ✅ CRITÈRES POSITIFS:
   • Traumatisme crânien certain avec coma initial
   • Délai d'apparition: 3 mois minimum à 1 an maximum
   • EEG: perturbations focalisées ou bilatérales synchrones
   • Crises précoces possibles si traumatisme grave
   • Traitement antiépileptique suivi
   
   ❌ CRITÈRES NÉGATIFS:
   • Crises précoces après traumatisme bénin
   • EEG: pointes-ondes 3 c/s (épilepsie idiopathique)
   • Épilepsie photosensible
   • Absence de coma initial
   
   🔬 INVESTIGATIONS NÉCESSAIRES:
   • EEG (de préférence avec suspension traitement 24h)
   • Interrogatoire entourage (morsure langue, incontinence, chutes)
   • Attestations médicales du suivi
   • Vérification du traitement effectif

## 🔄 PROGRESSION LOGIQUE DES TAUX
═══════════════════════════════════════════════════════════════

L'application respecte une progression logique selon:

1. TYPE DE CRISE (gravité intrinsèque):
   ────────────────────────────────────────────────────────────
   Généralisées > Jacksoniennes étendues > Jacksoniennes limitées
      (30-100%)      (10-40%)                (0-30%)
   
   Équivalents avec chute > Équivalents simples
      (40-80%)                (0-50%)

2. FRÉQUENCE DES CRISES:
   ────────────────────────────────────────────────────────────
   Quotidienne → Plurihebdomadaire → Hebdomadaire → 
   Mensuelle → Annuelle
   
   100% → 40-80% → 20-40% → 10-30% → 0-20%

3. PHARMACORÉSISTANCE (rateCriteria):
   ────────────────────────────────────────────────────────────
   Bien contrôlée par monothérapie → Taux bas de fourchette
   Pharmacorésistante → Taux élevé de fourchette

4. RETENTISSEMENT SOCIAL/PROFESSIONNEL:
   ────────────────────────────────────────────────────────────
   Activités normales maintenues → Taux bas
   Retentissement majeur → Taux élevé
