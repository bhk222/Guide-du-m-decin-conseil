📋 BARÈME 1939 - Psychoses Chroniques Post-Traumatiques
────────────────────────────────────────────────────────────────────────────

A) ÉTATS DÉMENTIELS INCOMPLETS (liés ou non à un substratum anatomique)

1. ✅ Troubles de l'attention, mémoire, vitalité générale
   └─ Syndrome post-commotionnel tardif grave
   └─ Taux : 5-25%
   └─ APPLICATION : ✅ "Démence post-traumatique incomplète" [60-90%]
   └─ NOTE: Application couvre forme plus sévère (60-90%) mais pas forme légère (5-25%)

2. ✅ État démentiel important (inactivité professionnelle)
   └─ Sans inaptitude totale à la vie sociale
   └─ Taux : 25-75%
   └─ APPLICATION : ✅ "Démence post-traumatique incomplète" [60-90%]
   └─ NOTE: Taux application décalé vers le haut (60-90% vs 25-75%)

B) ÉTAT DÉMENTIEL COMPLET

3. ✅ Inaptitude à toute vie sociale → État démentiel avec gâtisme
   └─ Nécessité internement ou surveillance familiale permanente
   └─ Taux : 75-100%
   └─ APPLICATION : ✅ "Démence post-traumatique complète" [100%]
   └─ NOTE: Application = taux fixe 100%, barème 1939 = 75-100%

C) ÉTATS PSYCHOTIQUES SPÉCIFIQUES

4. ❌ MANQUANT: État maniaco-dépressif (non imputable)
   └─ Taux : Généralement non imputable
   └─ APPLICATION : ❌ Non mentionné explicitement comme non imputable
   └─ NOTE: Mais application a "Trouble bipolaire post-traumatique" [40-80%]

5. ✅ Schizophrénie traumatique
   └─ Conditions strictes : intégrité mentale antérieure + traumatisme grave
   └─ Dissociation dissociative modérée dépressive (5-100%)
   └─ Imputabilité partielle possible (1/3, 1/2, exceptionnellement totale)
   └─ APPLICATION : ✅ "Schizophrénie post-traumatique" [60-100%]
   └─ NOTE: Taux élevé (60-100%), imputabilité partielle non codifiée

6. ❌ MANQUANT: Schizophrénie paranoïde (difficile à imputer)
   └─ Taux : Variable selon imputabilité
   └─ APPLICATION : ✅ Couvert par rateCriteria (low: "paranoïde")

7. ❌ MANQUANT: Hébéphrénie (très difficile à imputer)
   └─ Taux : Variable selon imputabilité
   └─ APPLICATION : ✅ Couvert par rateCriteria (high: "désorganisée")

D) COMPLICATIONS DÉMENCES ARTÉRIOPATHIQUES ET DÉGÉNÉRATIVES

8. ❌ MANQUANT: Démences artériopathiques (rôle favorisant)
   └─ Taux : Imputabilité partielle ou nulle
   └─ APPLICATION : ❌ Non mentionné

9. ❌ MANQUANT: Maladie de Pick (rôle favorisant possible)
   └─ Taux : Imputabilité très limitée
   └─ APPLICATION : ❌ Non mentionné

10. ❌ MANQUANT: Maladie d'Alzheimer (rôle favorisant possible)
    └─ Taux : Imputabilité très limitée
    └─ APPLICATION : ❌ Non mentionné

11. ❌ MANQUANT: Paralysie générale (non imputable)
    └─ Taux : Imputabilité nulle ou rôle favorisant minime
    └─ APPLICATION : ❌ Non mentionné

E) COMPLICATIONS ALCOOLISME

12. ❌ MANQUANT: Delirium tremens post-traumatique
    └─ Taux : Rôle favorisant 50% si mort
    └─ État démentiel ultérieur : imputabilité ≤50%
    └─ APPLICATION : ❌ Non mentionné

13. ❌ MANQUANT: Encéphalopathie de Gayet-Wernicke
    └─ Taux : Rôle accessoire
    └─ APPLICATION : ❌ Non mentionné

F) COMPLICATIONS ÉPILEPSIE TRAUMATIQUE

14. ✅ Troubles psychiques liés à épilepsie traumatique
    └─ Irritabilité, instabilité, troubles caractère, impulsivité
    └─ Désintérêt intellectuel (lié au traitement anticomitial)
    └─ Taux : 5-15% (EN PLUS des autres séquelles)
    └─ APPLICATION : ⚠️ PARTIEL - Couvert indirectement via épilepsie
    └─ NOTE: Barème prévoit ajout 5-15%, application non explicite

📋 BARÈME 1939 - Névroses Post-Traumatiques
────────────────────────────────────────────────────────────────────────────

A) ÉTATS NEURO-PSYCHASTHÉNIQUES (Épuisement + Hyper-émotivité anxieuse)

A.1 - CAS À PRÉDOMINANCE D'ÉPUISEMENT

15. ✅ Signes fonctionnels somatiques SANS symptômes objectifs
    └─ Réaction émotionnelle causée par accident
    └─ Taux : 0-10%
    └─ APPLICATION : ✅ "États neuro-psychasthéniques (signes fonctionnels)" [0-10%]
    └─ CONFORMITÉ : ✅ PARFAITE (taux identique)

16. ✅ Signes somatiques AVEC retentissement net sur l'état général
    └─ Taux : 10-40%
    └─ APPLICATION : ✅ "États neuro-psychasthéniques (signes somatiques)" [10-40%]
    └─ CONFORMITÉ : ✅ PARFAITE (taux identique)

17. ✅ Signes psychiques (fatigabilité cérébrale → impuissance intellectuelle)
    └─ Consciente
    └─ Taux : 20-50%
    └─ APPLICATION : ✅ "Signes psychiques (fatigabilité cérébrale)" [20-50%]
    └─ CONFORMITÉ : ✅ PARFAITE (taux identique)

18. ✅ Symptômes vago-sympathiques marqués ou prédominants
    └─ EN PLUS de l'invalidité ci-dessus
    └─ Taux : 5-20%
    └─ APPLICATION : ✅ "Symptômes vago-sympathiques" [5-20%]
    └─ CONFORMITÉ : ✅ PARFAITE (taux identique)

A.2 - CAS À PRÉDOMINANCE D'HYPER-ÉMOTIVITÉ ANXIEUSE

19. ✅ Syndromes anxieux provoqués par gros accident
    └─ Explosions, électrocutions, etc.
    └─ Taux : 10-50%
    └─ APPLICATION : ✅ "Syndromes anxieux" [10-50%]
    └─ CONFORMITÉ : ✅ PARFAITE (taux identique)

B) ÉTATS HYSTÉRIQUES ET PITHIATIQUES

20. ✅ Manifestations pithiatiques isolées
    └─ Taux : 0% (n'entraînent pas d'invalidité)
    └─ APPLICATION : ⚠️ PARTIEL - Non explicite, mais implicite dans évaluation
    └─ NOTE: Principe respecté (évaluation selon troubles organiques seuls)

21. ✅ Manifestations pithiatiques + troubles organiques
    └─ Taux : Selon gêne des troubles organiques uniquement
    └─ APPLICATION : ⚠️ PARTIEL - Non explicite, mais implicite dans évaluation
    └─ NOTE: Principe respecté (évaluation selon troubles organiques seuls)

C) SYNDROMES MOTEURS FONCTIONNELS

22. ✅ Sans base organique décelable
    └─ Taux : 0-20%
    └─ APPLICATION : ✅ "Syndromes moteurs fonctionnels" [0-20%]
    └─ CONFORMITÉ : ✅ PARFAITE (taux identique)

📋 BARÈME 1939 - Classification Détaillée des Névroses
────────────────────────────────────────────────────────────────────────────

a) RÉACTION D'EFFROI

23. ✅ Réaction d'effroi (excitation anxieuse ou prostration)
    └─ Évolution : Guérison en quelques jours/semaines
    └─ Séquelles : Anxiété, irritabilité, insomnie, amaigrissement
    └─ Taux : 0-5%
    └─ APPLICATION : ⚠️ PARTIEL - Couvert par "Trouble de l'adaptation" [5-15%]
    └─ NOTE: Taux application plus élevé (5-15% vs 0-5%)

24. ❌ MANQUANT: Confusion mentale grave post-effroi
    └─ Peut aboutir à la mort ou état psychotique
    └─ Taux : Selon gravité
    └─ APPLICATION : ❌ Non explicite (couvert par psychoses?)

b) NÉVROSE D'ANGOISSE/NEURASTHÉNIE POST-TRAUMATIQUE

25. ✅ Dépression névrotique/hypocondriaque simple
    └─ Avec perturbations neuro-végétatives
    └─ Taux : 0-25%
    └─ APPLICATION : ✅ Couvert par "États neuro-psychasthéniques" [0-40%]
    └─ NOTE: Application plus large (0-40%)

26. ✅ Dépression avec retentissement état général + amaigrissement
    └─ Taux : 25-40%
    └─ APPLICATION : ✅ "États neuro-psychasthéniques (somatiques)" [10-40%]
    └─ NOTE: Borne inf. plus basse dans application (10 vs 25%)

c) PHÉNOMÈNES PHOBIQUES ASSOCIÉS

27. ✅ Phobies importantes associées à névrose d'angoisse
    └─ Taux : 5-35%
    └─ APPLICATION : ✅ "Phobie spécifique post-traumatique" [5-20%]
    └─ NOTE: Borne sup. plus basse dans application (20% vs 35%)

28. ❌ MANQUANT: Névrose obsessionnelle post-traumatique
    └─ Exceptionnelle
    └─ Taux : Variable
    └─ APPLICATION : ✅ Ajout moderne "TOC post-traumatique" [20-60%]
    └─ NOTE: Application plus complète que barème 1939

d) RÉACTIONS HYSTÉRIQUES (HYSTÉRO-TRAUMATISME)

29. ✅ Conversion somatique (paralysie, contracture)
    └─ Levée par persuasion, mais récidivante
    └─ Taux : 0-5% (sauf cas rebelles)
    └─ APPLICATION : ⚠️ PARTIEL - Couvert par "Syndromes moteurs fonctionnels" [0-20%]
    └─ NOTE: Borne sup. plus élevée dans application (20% vs 5%)

30. ✅ Conversion physiologique (végétative, névrose d'organe)
    └─ Maladie psychosomatique
    └─ Taux : 0-15%
    └─ APPLICATION : ✅ "Trouble somatoforme douloureux persistant" [10-30%]
    └─ NOTE: Borne inf. plus élevée (10% vs 0%), borne sup. doublée (30% vs 15%)

31. ✅ Conversion psychologique (dépression, obsessions, phobies)
    └─ Difficulté d'authentifier (simulation possible)
    └─ Taux : 5-50% (cas rebelles, après échec thérapeutique)
    └─ APPLICATION : ✅ Multiples items modernes couvrant ces aspects
    └─ NOTE: Application plus détaillée

e) NÉVROSE DE REVENDICATION

32. ✅ Névrose de revendication
    └─ Désir légitime de justice (non pathologique)
    └─ Taux : 5% (s'ajoute aux autres taux si autres lésions)
    └─ APPLICATION : ❌ MANQUANT - Non codifié explicitement
    └─ NOTE: Problème délicat, principe à ajouter

f) SINISTROSE

33. ✅ Sinistrose (surestimation inconsciente du dommage)
    └─ Définition Brissaud : idée fausse de revendication en bonne foi
    └─ Différent de simulation (surestimation consciente)
    └─ Disparaît souvent avec règlement du litige
    └─ Taux : 5%
    └─ APPLICATION : ❌ MANQUANT - Non codifié explicitement
    └─ NOTE: Problème médico-légal important à ajouter

g) CAS MIXTES (ORGANIQUE + NÉVROTIQUE)

34. ✅ Interférence atteinte organique + majoration névrotique
    └─ Taux : +5% maximum (en plus de l'indemnisation organique)
    └─ APPLICATION : ❌ MANQUANT - Principe non codifié explicitement
    └─ NOTE: Règle importante pour cas mixtes
